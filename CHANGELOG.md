# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-27
### Added
- Initial enterprise release of Azure Landing Zone Governance module.
- Modular Policy definitions for allowed regions, mandatory tagging, and storage encryption.
- Custom Governance Initiative (Policy Set) bundle.
- Pre-configured dev and prod environment roots.
- GitHub Actions CI/CD workflows for linting, validation, and Checkov security scanning.
- Azure DevOps YAML pipeline template.
- Comprehensive technical documentation and Mermaid architectural diagrams.
