# Contributing to Azure Landing Zone Governance

We welcome contributions to enhance security guardrails, policy initiatives, and compliance coverage!

## Guidelines
1. Fork the repository and create a descriptive feature branch (`feature/policy-enhancement`).
2. Adhere to standard Terraform styling (`terraform fmt`).
3. Ensure all variables have descriptive text and strict type constraints.
4. Run `tflint` and `checkov` before submitting PRs.
5. Provide clear problem and resolution summaries in Pull Requests.
